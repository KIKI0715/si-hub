# 스마트 인터랙션 디자인 · 제출 허브

학생이 낸 링크를 한 화면에서 열어 보는 곳입니다. 교수자 모드에서는 결과물 옆에 판단 기준을 두고 채점 내용을 적습니다.
자동으로 채점하지 않습니다.

## 누가 무엇을 보나
| | 공개 보기 | 교수자 모드 (접속 코드) |
|---|---|---|
| 학생 표시 | 별칭 (예: S01) | 이름 · 학번 |
| 결과물 | 보임 | 보임 |
| 판단 기준 · 점수 | 안 보임 | 보이고 적을 수 있음 |

이 저장소에는 실명·학번·성적이 없습니다. 그 셋은 비공개 구글 시트에만 있고, 허브는 접속 코드가 맞을 때만 읽고 씁니다.

## 파일
| 파일 | 내용 |
|---|---|
| `students.js` | 별칭과 제출 링크 |
| `rubric.js` | 판단 기준 (기말: 교수님 기말과제 안내의 평가 기준) |
| `link-status.js` | 링크 점검 결과. 자동으로 고쳐집니다 |
| `check_links.py` | 링크를 로그인 없이 열어 보고 표시 방식을 정함 |
| `config.js` | 비공개 저장소 주소 |
| `index.html` | 허브 화면 |

## 링크를 받았을 때
`students.js` 에 별칭과 링크를 넣어 올리면 끝입니다. 올라가면 링크 점검이 자동으로 돌고, 몇 분 뒤 허브에 반영됩니다.
점검은 하루 한 번(06:00) 다시 돕니다. 링크마다 셋 중 하나로 표시됩니다.

- 화면 표시: 허브 안에 바로 보임
- 새 탭으로만 열림: 그 사이트가 다른 화면 안에 넣는 것을 막음
- 열리지 않음: 로그인 없이 안 열림 → 다시 받기

한 주소 안에 번호별 화면이 있으면(`주소/01`, `주소/23` …) `numbered` 를 적어 번호 버튼으로 열 수 있습니다.
