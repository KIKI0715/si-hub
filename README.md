# 스마트 인터랙션 디자인 · 제출 허브

학생이 낸 링크를 한 화면에서 열어 보는 곳입니다. 계정으로 들어온 사람만 봅니다.
결과물 옆에 판단 기준을 두고 채점 내용을 적습니다. 자동으로 채점하지 않습니다.

## 이 저장소에 있는 것과 없는 것

있는 것은 허브 화면과 판단 기준뿐입니다.
수강생 목록, 제출 링크, 실명, 학번, 성적, 계정은 이 저장소에 없습니다. 비공개 구글 시트에만 있고, 허브는 로그인한 사람에게만 그 내용을 받아 보여 줍니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 허브 화면 (로그인 화면 포함) |
| `rubric.js` | 판단 기준 (기말: 교수님 기말과제 안내의 평가 기준 · 기말 기획서: 같은 안내의 12주 할 일) |
| `config.js` | 비공개 저장소 주소 |
| `c/` | 이름을 가린 제출물 사본 |

## 역할

| | 열람 | 교수자 |
|---|---|---|
| 학생 표시 | 별칭 (예: S01) | 이름 · 학번 |
| 결과물 | 보임 | 보임 |
| 판단 기준 · 점수 | 안 보임 | 보이고 적을 수 있음 |

## 링크를 받았을 때

비공개 시트의 `과제 링크` 탭에 한 줄을 더합니다. 저장소에는 올릴 것이 없습니다.

| 칸 | 적는 것 |
|---|---|
| 별칭 | `S01` 처럼 명단의 별칭 |
| 과제 | `w10`(10주차) · `w11`(11주차) · `plan`(기말 기획서) · `final`(기말) |
| 표시 이름 | 허브의 탭에 보일 이름 |
| 주소 | `https://` 로 시작하는 주소 |
| 번호별 화면 | 한 주소 뒤에 번호를 붙여 여는 경우에만. `전체` 또는 `1,2,23` |
| 번호 주소 모양 | 번호별 주소가 `/01` 모양이 아닐 때만. 예: `#/{nn}`, `?n={n}` |

링크 점검은 시트 쪽에서 하루 한 번(06:00) 돕니다. 바로 돌리려면 시트 메뉴 **허브 → 링크 다시 점검**을 누릅니다. 링크마다 셋 중 하나로 표시됩니다.

- 화면 표시: 허브 안에 바로 보임
- 새 탭으로만 열림: 그 사이트가 다른 화면 안에 넣는 것을 막음
- 열리지 않음: 로그인 없이 안 열림 → 다시 받기

## 계정

계정은 비공개 시트의 메뉴 **허브**에서 만들고 지웁니다. 계정에 관한 내용은 이 저장소와 커밋 메시지에 적지 않습니다.
